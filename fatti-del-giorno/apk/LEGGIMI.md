# L'APK pronto da installare

`FattiDelGiorno.apk` è l'app compilata, firmata e pronta da aprire sul telefono.

Una volta che questa cartella è sul ramo principale, l'indirizzo da aprire dal
telefono è:

```
https://costalonga.org/fatti-del-giorno/apk/FattiDelGiorno.apk
```

Android chiede il permesso di installare da questa origine: va concesso al
browser o al gestore dei file che si sta usando. Serve Android 8.0 o successivo.

Questo file è la versione compilata al momento dell'ultima modifica del codice.
L'ultima in assoluto sta sempre fra i file dell'esecuzione più recente del
flusso **Fatti del Giorno · app Android** nella scheda Actions del deposito.
