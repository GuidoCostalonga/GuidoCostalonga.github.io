# Atlante dei dati

Copia pubblicata dell'Atlante dei dati, servita su https://costalonga.org/atlante/.

Il sorgente, i dati originali e lo script che rigenera i file di `dati/` stanno nel
repository [open-data](https://github.com/GuidoCostalonga/open-data), cartella `atlante/`.
Per aggiornare: rigenerare lì, poi ricopiare qui `index.html`, `stile.css`, `app.js` e `dati/`.
